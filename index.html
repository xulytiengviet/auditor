Auditor hoạt động như thế nào?
  • Phân tích: đọc yêu cầu, xây dựng phạm vi, nhận diện rủi ro.
  • Triển khai: viết hoặc chỉnh sửa mã theo kế hoạch.
  • Kiểm thử: chạy kiểm tra phù hợp với ngôn ngữ dự án.
  • Rà soát: đánh giá bảo mật, chất lượng và quy tắc mã.
Phân biệt hai chế độ vận hành
  • 100x CLI: quy trình phát triển mã dựa trên Claude Code và công cụ shell.
  • DeepSeek Pipeline: luồng nghiên cứu đa tác tử qua Python và API.
  • Trang web này: hướng dẫn + mô phỏng cục bộ, không gọi API và không quét repository.
Phạm vi: Auditor trong repository này là bộ công cụ quy trình kỹ thuật phần mềm, không phải dịch vụ quét lỗ hổng website trực tiếp. Các số liệu hiệu quả trong tài liệu nghiên cứu là tham chiếu, không phải cam kết kết quả cho mọi dự án.

Các thành phần bao quanh quy trình

Harness dùng quy tắc dự án, context và hướng dẫn theo từng giai đoạn. Quality gate kiểm tra mã; budget hạn chế chi phí và rủi ro vòng lặp. Kết quả thực phụ thuộc công cụ, model, cấu hình và thử nghiệm của từng dự án.

Lệnh 100x gate nhận diện loại dự án và chạy chuỗi kiểm tra phù hợp. Bảng dưới đây tóm tắt nhóm kiểm tra được README mô tả, không phản ánh việc đã chạy kiểm thử trên thiết bị hiện tại.

  • Ưu tiên kiểm thử tự động và đánh giá có thể lặp lại.

MODULE: AGENTS.DBF / MULTI-AGENT DISPATCH

Điều phối nghiên cứu đa tác tử DeepSeek

Bộ Python cho phép chạy nhiều nhiệm vụ độc lập, tổng hợp kết quả và xuất dashboard HTML. Tham số --agents là giới hạn tác tử hoạt động đồng thời, không mặc định là số tác vụ thực tế của preset.

CHẾ ĐỘ XEM TRƯỚC · KHÔNG TIÊU THỤ API
python3 runner.py --preset market_scan --topic "Vietnamese AI tools" --agents 20 --budget 5 --dry-run
Khuyến nghị: chạy --dry-run để quan sát kế hoạch trước khi chạy thực. Không nhập API key vào trang web này hoặc đưa key vào repository.

Thực thi 100 tác vụ có khác 100 tác tử đồng thời?

Khác nhau. Một tệp cấu hình có thể liệt kê nhiều pha và 100 tác vụ; nếu đặt --agents 20, tối đa 20 yêu cầu được thực thi đồng thời tùy thiết kế runner, tài nguyên và giới hạn nhà cung cấp. Kết quả thật cần được đối chứng; không nên mặc định tất cả tác tử đều đưa ra kết luận đúng.

MODULE: SETUP.PRG / COMMAND WINDOW

Cài đặt và chạy trên máy tính

Mã nguồn bao gồm hai luồng: 100x CLI dùng Bash + Claude Code, và DeepSeek Python pipeline dùng Python 3.9+ cùng thư viện httpx. Chọn đúng môi trường trước khi chạy.

Phương án A · DeepSeek Python (Windows PowerShell)

01 / TẢI MÃ & CÀI PHỤ THUỘC
git clone https://github.com/xulytiengviet/auditor.git
cd auditor
python -m pip install httpx
cd pipeline
python runner.py --preset code_review --topic "Python code quality" --agents 5 --budget 5 --dry-run
02 / CHẠY THỰC SAU KHI CẤU HÌNH KEY
# Nhập khóa vào biến môi trường của phiên PowerShell
$env:DEEPSEEK_API_KEY = "NHAP_KHOA_CUA_BAN"
python runner.py --preset code_review --topic "Python code quality" --agents 5 --budget 5
Lệnh thứ hai sẽ sử dụng API trả phí theo bảng giá hiện hành và chỉ nên chạy sau khi kiểm tra ngân sách. Không chia sẻ khóa thật, ảnh chụp terminal chứa khóa hoặc commit khóa vào Git.

Phương án B · 100x CLI (Linux / macOS / WSL2)

03 / MÔI TRƯỜNG BASH + CLAUDE CODE
git clone https://github.com/xulytiengviet/auditor.git
cd auditor
# Yêu cầu: git, jq, bc và Claude Code CLI
chmod +x 100x
./100x doctor
./100x init
./100x gate
Trên Windows, dùng WSL2 nếu muốn chạy trọn vẹn shell pipeline. Quy trình CLI có thể yêu cầu xác thực Claude Code; website không chạy thay các lệnh này.
